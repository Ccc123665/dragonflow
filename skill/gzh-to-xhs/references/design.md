# 小红书图文设计规范（暖橙奶油 · 杂志干货风）

整体气质：**像一本纸质杂志的信息图**。奶油白底 + 深棕墨色大字 + 暖橙点缀，去掉所有渐变、光晕、网点，靠**大留白、粗标题、细线分栏、深底数据块**做出高级感。

## 画布

- 尺寸 **1080 × 1440**，正好 3:4，适配首页推荐和沉浸式阅读
- 顶部 14px 深棕墨横条作为品牌识别（所有页统一）
- 安全边距：左右各 72px

| 浅杏底 | `#F5E7D3` (245,231,211) |
| 交替行 | `#FDF7EF` (253,247,239) |
| 正文墨黑 | `#261F19` (38,31,25) |

配色纪律：
- **深色不铺满**。深棕墨只用在：顶部条、刊头条、表格表头、底部大块数据卡、深色收尾卡。其余区域保持奶油底呼吸感。
- 暖橙是高光色，一张图里**最多 3 处**（粗短条 / 关键词 / 一个重点数值），用多了就low。
- 焦糖金留给数据卡里的大数字和封面小标签，避免和暖橙打架。

## 版式

### 封面（杂志刊头感）

自上而下：

1. 顶部 14px 深棕墨条
2. **刊头条**：左侧深棕墨胶囊标签（奶油字，写"年份 + 主题"），右侧灰棕小字（`"NO.01 / 备考手册"` 这类刊号，右对齐）；下方一条贯穿的细分割线 `#E8DCC8`
3. **引题**：64px 焦糖金，一行短词（如"一文读懂"）
4. **主标题**：124px 深棕墨，2 行；其中**一个关键词用暖橙**，形成视觉落点
5. 橙色短粗条（84→300，高 8px）
6. **副标题**：40px 正文墨（一行内解决问题）+ 30px 次要灰棕（补充说明，一行）
7. **底部大块数据卡**：跨 72→1008 的深棕墨圆角卡（r=36，高 320），内部三等分：每块一个 72px 焦糖金大数字 + 单位（奶油）+ 24px 说明（浅灰）；**用竖向 2px 细线分栏**，不要画三张小卡——杂志感来自整块底色，不是卡片堆叠
8. 卡下方一行：左灰棕注释、右侧暖橙胶囊"建议收藏"

禁止：渐变、高斯模糊光晕、网点、斜切装饰条、任何 emoji。装饰只用**直线、细圆环、纯色块**。

### 内容页

- 胶囊标签 → 大标题 → 一句话副标题 → 橙色短条 → 内容卡片区
- **内容卡片**：白底圆角 26-28，左侧 14px 竖条做颜色区分（深棕墨=常规、暖橙=重点、灰=已过时/次要），带暖色投影
- **数值强调**：题量、比例这类数字用胶囊 pill 承载，重点项用暖橙底白字
- **收尾页**：深棕墨大卡片 + 橙色圆形序号 + 奶油色条目

## 投影

```python
def shadow(base, box, r=28, dy=10, blur=22, alpha=38):
    layer = Image.new("RGBA", base.size, (0, 0, 0, 0))
    ImageDraw.Draw(layer).rounded_rectangle(
        (box[0], box[1] + dy, box[2], box[3] + dy), radius=r, fill=(72, 54, 38, alpha))
    base.alpha_composite(layer.filter(ImageFilter.GaussianBlur(blur)))
```

注意：投影颜色必须是暖棕 `(72,54,38)` 而不是灰黑/深蓝，冷色投影会破坏奶油底的暖调。

## 文本块间距（最容易叠字的地方）

**"小标签 + 大数字"卡片必须手算间距，不能凭感觉给 y 值。**

坑在于：`anchor="lm"` 是把字体的 `ascent+descent` 盒子在给定 y 上垂直居中，不是把字形居中。所以一个 96px 的字，锚点在 y+108 时，字形顶部其实在 y+74 附近——上面 30px 的标签就会和它压在一起。

估算公式（微软雅黑）：

```
字形高  ≈ 字号 × 0.72
字形顶  = 锚点y − 字号 × 0.44      （anchor="lm"）
字形底  = 锚点y + 字号 × 0.44
文字块底 = 文字顶y + 字号 × 1.1     （d.text 默认 anchor="la"）
```

**要求：任意两块之间字形净间距 ≥ 24px。**

一组验证过的数值（卡片内，y 为卡片顶部）：

| 元素 | 字号 | y 偏移 | 卡片高 |
| --- | --- | --- | --- |
| 小标签 | 30 | +58 | 330 |
| 大数字 | 96 | 中心 +202 | — |
| 单位"周岁" | 32 | 中心 +230 | — |

小标签 + 中数字（横排三卡）：
| 标签 | 26 | +56 | 250 |
| 数字 | 56-58 | 中心 +152 | — |
| 单位 | 26 | 中心 +168 | — |

封面数据卡（深底，y 为卡顶部）：
```
大数字 中心 y+126，字号 72（字形 94..158）
说明   y+196 顶（字形 201..222）
卡片高 320 → 底部留 ~98
```
净间距 158→201 = 43。稳妥。

**检查方法**：出图后逐张 Read，重点看"小字是否贴住大字"、"最后一行是否贴住卡片底边"。贴边小于 20px 就是没留够，要加高卡片。

## 表格页（考情/竞争比类内容必备）

- 表头行：深棕墨圆角矩形，奶油色字，居中
- 数据行：偶数行交替色 `#FDF7EF`，行间 2px 分隔线 `#E8DCC8`
- 首列左对齐加粗，末列（数值列）右对齐加粗，中间列居中灰棕字
- 重点值用暖橙，合计行整行浅杏底 `#F5E7D3` + 深棕墨加粗
- 值为 0 或"—"的格子用浅灰棕 `(206,192,172)`，一眼看出"这年没考/数据缺失"

**行高与溢出（最容易翻车的地方）**

内容区可用高度约 **960px**（y 从 480 到 1440，底部留 ~60px 给注释）。

```
总高 = header_h(78~84) + 行数 × row_h
row_h 取 74~96：行数多就压到 74
```

- 8 行以内 → row_h 96
- 9-11 行 → row_h 74
- 超过 11 行 → 拆成两张表（如"（上）/（下）"）

**出图后必须逐张 Read 检查最后一行有没有被裁掉**，溢出不会报错，只会静默丢内容。

## 中文换行

按字符逐字测宽，`font.getlength(cur + ch) <= maxw` 就累加，超了就换行。中英混排不需要特殊处理。

## 绝对不要

- 不要 emoji（PIL 无彩色 emoji 字体，渲染成豆腐块）
- 不要透明 fill 直接画在 RGBA 画布上（会覆盖底色）
- 不要外链、二维码、机构 logo、水印
- 不要渐变、光晕、网点、斜切贴纸风——考公/教培受众吃"克制的杂志干货风"
- 不要冷色调（深蓝、灰黑、荧光色），一律走暖色闭环
